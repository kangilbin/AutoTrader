# 사전 등록 3 — 표준 일목균형표(삼역호전/역전) 전략 검증 (2026-11-25, 결과 보기 전 고정)

## 질문
보편적으로 쓰는 일목 매매(삼역호전 진입, 구름·기준선 이탈 또는 삼역역전 청산)가 이 종목군·구간에서 "같은 낙폭의 지수 + 예금" 단순 선을 이기는가?
앞선 "구름 눌림목" 연구(`ichimoku_pullback.py`, 시도 8회)와는 **다른 규칙 계열**이다. 표준 기간 **9 / 26 / 52** 는 고정하며 튜닝하지 않는다.

## 규칙 (지표는 종가 확정값만, 신호는 t 종가에 판정 → t+1 시가 체결)
정의: 전환선 = (9일 고저 중간값), 기준선 = (26일 고저 중간값), 선행스팬 A = (전환선+기준선)/2 를 26봉 시프트, 선행스팬 B = (52일 고저 중간값)을 26봉 시프트,
구름 상단/하단 = 선행스팬 A·B 중 큰 값/작은 값, 후행 조건 = 종가 > 26봉 전 종가.

**진입 후보**
- **E1 삼역호전**: ① 전환선 > 기준선, ② 종가 > 구름 상단, ③ 종가 > 26봉 전 종가 — 세 조건이 **오늘 처음 모두 충족**된 날(전일은 미충족)
- **E2 TK 교차**: 전환선이 기준선을 상향 돌파(전일 전환선 ≤ 기준선, 오늘 >)하고 종가 > 구름 상단인 날

**청산 후보** (종가 기준 판정 → 다음 날 시가 매도)
- **X1** 종가 < 구름 하단
- **X2** 종가 < 기준선
- **X3 삼역역전**: 전환선 < 기준선 **그리고** 종가 < 구름 하단 **그리고** 종가 < 26봉 전 종가

후보 = E1/E2 × X1/X2/X3 = **6개**. 다른 변형(부분익절, 목표가, 필터 추가)은 만들지 않는다.
사이징용 초기 손절선(1R 기준): 진입 신호일의 X1 → 구름 하단, X2 → 기준선, X3 → 구름 하단. 초기 손절선이 진입가 이상이면 그 신호는 건너뛴다.
이 손절선은 **사이징에만** 쓰고 실제 청산은 각 후보의 청산 규칙으로만 한다 (갭 하락 손실은 R 을 넘을 수 있고 그대로 반영된다).

## 하네스
- `portfolio_sim.py` 재생 엔진 + `regime_exposure.BASE_KW` 와 같은 풀 설정(`mode=pool`, `risk_pct=0.007`, `max_position_pct=0.095`, `max_positions=10`, `priority=narrow_stop`) + 파킹 수익(`park_apy` 한국 3% · 미국 4%).
- 개발 구간 2020-05-01 ~ 2026-10-23. 홀드아웃 2015-01-01 ~ 2019-12-31 (이 연구 전용 마커 `.holdout_ichimoku_std_done`, **단 1회**). 한국·미국 따로 운용.
- 참고 기준선 B0 = 현행 20EMA 풀(같은 설정). 판정에는 쓰지 않는다.

## 대조군
- **C2 무작위 시점**: 종목별 진입 신호 열을 달력 위에서 **원형 이동**(오프셋은 시드 0~29와 종목 코드로 결정, 재현 가능)한 30개. 신호 빈도·군집은 같고 시점만 무너진다. 청산 규칙은 후보와 동일.

## 합격 기준 (후보 단위, 한국·미국 **모두** 충족)
- **P1**: 전략 CAGR ≥ "같은 MDD 가 되는 지수(069500 / SPY) + 예금(3% / 4%)" 선의 CAGR (매일 리밸런싱·비용 0 가정이라 선에게 유리한 기준)
- **P2**: MAR ≥ C2 30개 MAR 의 90분위 (`portfolio_sim.control_threshold`)
- **P3**: 수익 상위 10개 사이클을 뺀 뒤 다시 재생해도 MAR > 0
- **표본 규칙**: 한 시장이라도 체결 사이클이 60개 미만이면 그 후보는 불합격(검증 불충분).
- **홀드아웃**: 합격 후보가 있으면 `min(한국 MAR, 미국 MAR)` 최대 후보 **하나만** 홀드아웃에서 P1·P2·P3 를 동일 기준으로 평가하고, 모두 충족해야 최종 합격.

## 결과별 조치 (미리 정한다 — 사용자 결정 2026-11-25)
- **합격 후보 없음 / 홀드아웃 미합격**: 실전 코드를 바꾸지 않고 일목 연구를 종결한다. 규칙 변형·재시도 금지.
- **최종 합격**: 별도 설계 문서(신규 `SWING_TYPE` 로 추가, 기존 EMA 유지)를 승인받은 뒤 실전 구현으로 넘어간다. 그때도 "지수 + 예금 선" 대비 마진, 파킹 가정의 낙관성, 모의 계좌 전용 검증을 함께 보고한다.

## 보고 항목 (판정에 쓰지 않음)
후보별 체결 수·승률·평균 R·CAGR·MDD·MAR·평균 노출·연도별 수익, 같은 MDD 선의 CAGR, C2 분포, B0.
