# 사전 등록 4 — 대중적 일목 규칙(상태 기반) + 워크포워드 검증 (2026-11-26, 결과 보기 전 고정)

## 질문
"교차 하루"가 아니라 **상태**로 정의한 대중적 일목 규칙(구름 돌파 · 양운 유지 · 기준선 눌림 재진입)이, 훈련 구간에서 고른 값이 **보지 않은 구간·다른 시장**에서도 "같은 낙폭의 지수 + 예금" 선을 이기는가?
앞선 연구(눌림목 8회, 표준 E1/E2)와 규칙이 다르다. 표준 기간 **9 / 26 / 52** 고정, 튜닝하지 않는다. 지표는 종가 확정값만, 신호는 t 종가에 판정 → t+1 시가 체결.

## 정의
전환선·기준선·선행스팬 A/B(26봉 시프트)·구름 상단(top)/하단(bot)·후행 조건(종가 > 26봉 전 종가)은 `PREREG_ichimoku_standard.md` 와 같다.
양운 = 선행스팬 A > 선행스팬 B, 음운 = A < B. "구름 위" = 종가 > top.

**진입 5개**
- **A0 구름 돌파**: 종가가 top 을 상향 돌파(전일 종가 ≤ 전일 top, 오늘 > top) + 후행 조건
- **A1**: A0 + 양운
- **B0 상태 성립**: (구름 위 + 전환선 > 기준선)이 **최근 5거래일 안에 성립했고 지금도 유지** 중 (최근 5일 모두 이미 참이던 상태는 제외 = 막 성립한 상태)
- **B1**: B0 의 상태 정의에 양운을 추가
- **C 기준선 눌림 재진입**: 양운 + 구름 위 + 기준선 상승 중(기준선 > 5봉 전 기준선) + 당일 저가 ≤ 기준선 + 종가 > 기준선 + 양봉(종가 > 시가)

**청산 3개** (종가 기준 판정 → 다음 날 시가 매도)
- **X1** 종가 < top (구름 안으로 들어옴)
- **X2** 종가 < bot (구름 하단 이탈)
- **X3** 음운 전환(선행스팬 A < B) **또는** 종가 < bot

후보 = 5 × 3 = **15개** (표기 예: `A1-X2`). 다른 변형은 만들지 않는다. 사이징용 초기 손절선: X1 → top, X2·X3 → bot (진입가 이상이면 신호 건너뜀). 이 선은 사이징에만 쓴다.

## 하네스
`portfolio_sim.py` 재생 엔진, `regime_exposure.BASE_KW` 풀 설정(`risk_pct 0.007`, `max_position_pct 0.095`, `max_positions 10`, `narrow_stop`) + 파킹 수익(KR 3% · US 4%). 한국·미국 따로 운용. 각 구간은 **새 자본으로 독립 재생**하고 구간 끝에 보유분은 종가로 평가한다(지표는 구간 이전 데이터로 워밍업).

## 워크포워드 절차 (순서·횟수 고정)
1. **훈련** 2020-05-01 ~ 2023-06-30: 15개 후보를 한국·미국에서 한 번 평가. 선택 점수 = `min(한국 MAR, 미국 MAR)`. 두 시장 모두 사이클 ≥ 40 인 후보만 대상. 상위 **3개**를 선택해 파일로 **동결**한다 (`ichimoku_popular_train.json`).
2. **검증** 2023-07-01 ~ 2026-10-23: 동결된 3개만 **단 1회** 평가 (마커 `.valid_ichimoku_popular_done`). 후보별·시장별 판정:
   - **안정성**: 검증 MAR > 0 이고 훈련 MAR 의 50% 이상
   - **P1**: 전략 CAGR ≥ 같은 MDD 의 "지수(069500/SPY) + 예금" 선 CAGR
   - **P2**: 검증 MAR ≥ 무작위 시점 대조군 30개 MAR 의 90분위 (구간 안에서 진입 신호 열을 원형 이동, 시드·종목 코드로 재현)
   - **P3**: 수익 상위 **5개** 사이클을 뺀 재생에서도 MAR > 0
   - **표본**: 한 시장이라도 사이클 < 30 이면 불합격
   - 모든 항목을 두 시장에서 충족한 후보만 통과. 통과 후보 중 `min(한국, 미국) 검증 MAR` 최대 **하나**를 홀드아웃으로 보낸다.
3. **홀드아웃** 2015-01-01 ~ 2019-12-31 (마커 `.holdout_ichimoku_popular_done`, **단 1회**): 통과 후보 하나를 P1·P2·P3(상위 **10**개 제외)·표본(사이클 ≥ 60)으로 평가. 모두 충족해야 최종 합격. 실행 전에 신호 수만 점검(`holdout-check`, 성과 계산 없음).

## 결과별 조치 (미리 정한다)
- **검증 통과 후보 없음 / 홀드아웃 미합격**: 실전 코드를 바꾸지 않고 일목 연구를 최종 종결한다. 규칙·값을 바꾼 재시도 금지.
- **최종 합격**: 설계 문서를 먼저 승인받은 뒤 새 `SWING_TYPE` 로 추가(기존 EMA 유지), 모의 계좌에서만 검증. "지수 + 예금 선" 대비 마진과 파킹 가정의 낙관성을 함께 보고한다.

## 시도 횟수 통제
이 연구의 선택 자유도는 훈련 구간의 15개 후보뿐이다. 검증 구간은 한 번만 열고, 그 결과를 보고 후보를 바꾸지 않는다.

## 보고 항목 (판정에 쓰지 않음)
후보별 체결 사이클·승률·평균 R·CAGR·MDD·MAR·평균 노출·연도별 수익, 같은 MDD 선의 CAGR, 대조군 분포.

## 사전 예상
통과 확률은 낮게 본다(20% 안팎). 앞선 연구에서 진입 신호의 타이밍 가치가 거의 없었고, 상태 기반 규칙은 청산·노출이 성과를 좌우할 가능성이 크다.
