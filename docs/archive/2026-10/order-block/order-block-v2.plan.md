# 오더블럭 전략 v2 — 전문가 수준 설계 + 검증 체계

> 상태: **Plan (사용자 확인 전)** · 작성 2026-10-24
> 선행: v1 기획(`order-block-strategy.plan.md`) · v1 설계·결과(`docs/02-design/features/order-block-strategy.design.md` 12장)
> v1 결과: 국내 30·미국 13종목 2년, 비용 차감 후 국내 ≈ 본전, 미국 마이너스 (n=84, 우위 미확인)

## 0. 원칙 — 무엇이 "전문가 수준"인가

1. **조건은 가설이다.** 각 조건은 "왜 이게 수익을 내는가"를 한 줄로 설명할 수 있어야 하고, 데이터로 기여가 증명돼야 남는다.
2. **하나씩 빼 보며 증명한다 (Ablation).** 전체 조합에서 조건 하나를 끄면 성과가 나빠져야 그 조건이 일을 하는 것이다.
3. **대조군을 이긴다.** 같은 청산·사이징에 **무작위 진입**을 붙인 결과보다 나아야 "오더블럭 진입"에 가치가 있다.
4. **결과를 보기 전에 기준을 고정한다.** 고르는 기간과 확인하는 기간을 나눈다 (v1과 동일한 규율).
5. **표본이 충분해야 말할 수 있다.** 매매 300회 이상, 서로 다른 장세(상승·하락·횡보)를 포함해야 한다.

#### 5분 사이클 = 알고리즘 매매의 핵심 장점

사람은 차트를 띄엄띄엄 보지만, 배치는 **5분마다 빠짐없이** 본다. v2는 이를 세 가지로 살린다.

1. **장중 판단** — 3-2(저점 반등), 3-6(5분 BOS), 3-7(거래량 페이스)는 매 사이클 상태를 Redis에 남기고 다음 사이클과 비교해 판정한다 (단일 이평선의 연속 확인과 같은 구조를 반전 확인까지 확장).
2. **장중 청산** — 청산선 이탈은 이미 5분마다 판정한다 (종가까지 기다리지 않는다).
3. **장중 데이터 축적** — 5분 샘플(현재가·당일 고저·누적 거래량)을 **DB에 영구 저장**한다. 일봉 백테스트로는 3-2·3-6·3-7의 효과를 잴 수 없지만, 몇 달 쌓이면 실제 장중 경로로 이 규칙들을 검증할 수 있다. 저장은 오늘부터 시작할수록 빨리 검증할 수 있다.

## 2. 검증 체계

### 2.1 데이터

| 항목 | v1 | v2 목표 |
|------|----|---------|
| 종목 | 국내 30 + 미국 13 | **국내 100 + 미국 100** (시가총액 상위 + 업종 분산) |
| 기간 | 3년 (평가 2년) | **10년** (2016~2026 — 2018·2020·2022 하락장 포함) |
| 지수 | 없음 | KOSPI200 ETF, SPY |
| 생존 편향 | 현재 대형주만 | 한계로 명시 (상장폐지 종목 데이터 확보 어려움) |

KIS 일봉 조회가 10년치를 주는지 먼저 확인한다. 적재는 오늘 고친 적재 함수를 쓰고 `DATA_YN`은 원래 값으로 되돌린다.

### 2.2 비용

- 국내: 수수료 0.147%×2 + 거래세 0.20% (현행)
- 미국: 수수료 KIS 해외 요율로 분리 (현행은 국내 요율을 쓴다 — 수정 필요)
- 슬리피지: 진입·청산 각 호가 1틱 불리하게 추가

### 2.3 지표 (매매 단위 + 포트폴리오 단위)

순 기대값(R, 비용 차감) · 승률 · 손익비 · Profit Factor · 연간 매매 수 · 최대 낙폭(MDD) · 시장 노출 시간 · t-통계량 · 몬테카를로(매매 순서 1만 회 섞기)로 낙폭 95% 구간

### 2.4 절차 (결과 보기 전 고정)

1. **기간 분할** (7년 데이터로 확정, 2026-10-24): 학습 2020-05~2022-12 (2022 하락장 포함) / 검증 2023~2024 /
   최종 확인 2025-01~2026-10 (최종 확인은 마지막에 한 번만, `--final` 플래그 없이는 스크립트가 돌지 않는다)
2. **대조군**: 같은 청산·사이징 + 무작위 진입(같은 종목·같은 빈도, 1,000회 반복) → 오더블럭이 상위 5% 안에 들어야 "진입에 가치 있음"
3. **Ablation** (일봉으로 검증 가능한 조건만 — 1-1·1-2·2-2·2-3·2-4·2-7·3-2·4-2·4-4):
   - 단독 추가: v1 + 조건 하나 / 전체: v1 + 전부 / 전체 − 하나
   - **채택 규칙 (결과 보기 전 고정)**: 아래 둘 중 하나를 만족하는 조건만 남긴다
     - 전체에서 뺐을 때 학습·검증 **두 기간 모두** 순 평균 R이 나빠진다
     - 단독으로 넣었을 때 학습·검증 **두 기간 모두** 순 평균 R이 좋아지고, 매매 수가 v1의 30% 이상
   - 남은 조건 조합을 최종 후보로 하고, 아래 4·5를 적용한다
   - 장중 전용 조건(3-4·3-6·3-7)과 계좌 위험 한도(4-6)는 일봉으로 검증할 수 없어 5분 샘플이 쌓인 뒤 따로 판단한다
4. **민감도**: 남은 조건의 수치를 ±25% 흔들어도 성과가 무너지지 않아야 함 (봉우리 하나가 아니라 넓은 평지)
5. **채택 기준**: 검증 기간 순 기대값 > 0, t ≥ 2, 무작위 대조군 상위 5%, 최종 확인 기간에서도 순 기대값 > 0
6. 통과하면 모의투자 4주 → 실전 체결가와 백테스트 체결가 차이 측정

## 4. 한계 (미리 밝혀 둠)

- **우위가 없을 수 있다.** 전부 구현하고 검증해도 무작위 대조군을 못 이기면, 그게 결론이다. 그 경우 "오더블럭 진입은 이 시장에서 가치가 없다"를 증명한 것도 성과다.
- **조건이 많을수록 매매가 줄어든다.** 층 2를 다 켜면 연간 매매 수가 크게 줄 수 있다 — Ablation이 이를 걸러낸다.
- **3-2·3-4·3-6·3-7(장중 규칙)은 일봉 백테스트로 정확히 재현할 수 없다.** 일봉 근사로 방향만 보고,
  확정은 A0에서 쌓은 5분 샘플로 한다 (샘플이 몇 달 쌓이기 전까지는 모의투자 결과로 판단).
- **생존 편향**: 현재 상장 종목만 쓰면 성과가 부풀려진다.
