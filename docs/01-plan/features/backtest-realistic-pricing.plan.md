# Plan: 백테스팅 체결가 현실화 (Realistic Pricing)

## 개요
백테스팅에서 매수/매도 체결가를 종가(STCK_CLPR)나 저가(STCK_LWPR) 대신, **실제 신호 발생 가격**으로 변경하여 실전 매매와의 괴리를 줄인다.

## 문제 정의

### 현재 백테스팅 체결가 로직

| 거래 유형 | 현재 체결가 | 문제점 |
|-----------|-----------|--------|
| **매수** | `STCK_CLPR` (종가) | 장중에 신호 발생 시점 가격과 종가가 다름. 종가가 높으면 불리하게 매수 |
| **손절 매도** | `ema_atr_stop` (신호가) | ✅ 이미 올바르게 구현됨 |
| **1차 익절 매도** | `STCK_CLPR` (종가) | trailing stop 가격에 매도했어야 하는데 종가로 처리 |
| **2차 익절 매도** | `STCK_CLPR` (종가) | 동일 문제 |

### 핵심 원리

일봉 데이터에서 **고가(STCK_HGPR)와 저가(STCK_LWPR) 사이에 신호 가격이 존재**하면, 장중에 해당 가격을 지나갔다는 의미이므로 그 가격으로 체결된 것으로 처리해야 실전에 가까운 결과가 나온다.

```
당일 고가: 10,500원  ─┐
                      │ ← 이 범위 안에 신호 가격이 있으면
당일 저가:  9,800원  ─┘    해당 가격으로 체결 처리

예) 매수 신호 가격 = EMA20 = 10,100원
    → 저가(9,800) ≤ 10,100 ≤ 고가(10,500) → 10,100원에 매수 처리
    현재: 종가(10,400원)에 매수 → 300원 불리
```

## 변경 대상

### 파일
- `app/domain/swing/backtest/strategies/single_ema_backtest_strategy.py`

### 변경 항목

#### 1. 매수 체결가 변경 (line 108)
- **현재**: `buy_price = row["STCK_CLPR"]`
- **변경**: 시나리오별 신호 가격 계산 후, 해당 가격이 [저가, 고가] 범위 안이면 신호가로 체결
  - **시나리오 A (눌림목)**: `EMA20` (EMA 근접 매수이므로 EMA 값이 매수 시점 가격)
  - **시나리오 B (돌파)**: `EMA20` (EMA 돌파 시점 가격)
  - 범위 밖이면 기존처럼 종가 사용 (fallback)

#### 2. 1차 익절 체결가 변경 (line 82)
- **현재**: `row["STCK_CLPR"]` (종가)
- **변경**: `stop_price` (= `peak_price - ATR × 2.0`)
  - trailing stop이 트리거된 가격이 실제 매도 가격

#### 3. 2차 익절 체결가 변경 (line 96)
- **현재**: `row["STCK_CLPR"]` (종가)
- **변경**: `stop_price` (= `peak_price - ATR × 2.0`)
  - 동일하게 trailing stop 트리거 가격으로 매도

#### 4. _check_entry_conditions 반환값 확장
- 매수 신호가(signal_price)를 반환값에 추가하여 `compute()`에서 사용할 수 있도록 변경
- `Tuple[bool, List[str]]` → `Tuple[bool, List[str], Optional[float]]`

## 구현 순서

1. `_check_entry_conditions()` 반환값에 `signal_price` 추가
2. `compute()` 매수 로직에서 `signal_price`를 체결가로 사용 (범위 검증 포함)
3. `compute()` 1차/2차 익절 매도에서 `stop_price`를 체결가로 사용
4. README.md 업데이트 (체결가 로직 변경 반영)

## 예상 영향

- 매수가가 종가보다 낮아지는 경우 → 수익률 소폭 개선
- 익절 매도가가 종가보다 높아지는 경우 → 수익률 소폭 개선
- 전체적으로 **실전 매매 결과와 더 유사한 백테스팅 결과** 기대
- 기존 API 인터페이스 변경 없음 (내부 로직만 변경)

## 주의사항

- 손절 매도는 이미 `ema_atr_stop` 가격으로 처리되고 있으므로 변경 불필요
- 매수 신호가가 [저가, 고가] 범위 밖인 경우는 종가로 fallback (안전장치)
- 1차 익절 후 `peak_price` 리셋 시에도 `stop_price`로 리셋 (종가 대신)
