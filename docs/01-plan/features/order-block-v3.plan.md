## 3. v3 전략 설계

### 3.1 그대로 두는 것 (재튜닝 금지)

- OB 정의·탐지 필터(거래량 1.5·변위 2·EMA120): v2에서 완화·추가 조건 모두 탈락
- 청산 구조(버퍼 1.0·본전 없음·부분익절 없음·+2R부터 ATR×5): 27개 이웃 모두 플러스인 평지 — **더 다듬지 않는다** (스누핑 방지)

### 3.2 스윙별 배정금 구조 유지 (사용자 결정 2026-10-25)

서비스 구조 그대로 **종목마다 배정금을 따로 두고 각자 스윙 매매**한다. 수량은 현행대로 스윙 배정금의 2% 위험(상한 80%).
계좌 기준 위험·동시 보유 한도·총 위험 한도는 쓰지 않는다 — 스윙끼리 자금을 공유하지 않으므로 서로를 제한하지 않는다.
대신 3.4의 합산 곡선으로 "여러 스윙이 같은 날 손절되는" 위험이 얼마나 되는지 측정해 사용자에게 보여준다.

### 3.3 "좋은 OB"만 사기 — 품질 점수 문턱

신호가 나도 **품질 점수가 문턱보다 낮으면 건너뛴다.** 점수 요소(결과 보기 전 정의):

| 요소 | 의미 |
|------|------|
| 변위 크기 (BOS 종가 − OB 저가) / ATR | 클수록 강한 매집 흔적 |
| 임펄스 거래량 / 20일 평균 | 클수록 큰 주문 |
| 존 폭 / ATR | 좁을수록 R이 작아 손익비 유리 |
| 상대 강도 (종목 60일 수익률 − 지수 60일 수익률) | 시장보다 강한 종목의 눌림 |

점수 = 각 요소를 **그 시점까지의 과거 OB 분포**에서 매긴 백분위의 평균 (미래 OB와 비교하지 않는다 — 선견 방지).
"점수 상위 절반만 매수"가 "전부 매수"보다 나은지 검증한다 (4.4).

### 3.4 스윙 합산 시뮬레이터 (연구 스크립트 신규)

- 유니버스의 모든 종목에 **같은 배정금**의 스윙을 하나씩 둔다고 가정하고, 종목별 일별 평가금을 매일 합산
- 합산 자산 곡선으로 CAGR·MDD·샤프·최장 연패 등 4.3 지표를 계산 (스윙별 결과도 함께 남긴다)
- 국내·미국은 통화가 달라 **시장별로 따로** 합산한다

### 3.5 비용·체결 모델 강화

| 항목 | v2.1 | v3 |
|------|------|-----|
| 국내 비용 | 수수료 0.147%×2 + 거래세 0.20% | 동일 |
| 미국 비용 | 수수료 0.25%×2 | + **환전 0.25%×2** (원화 투자 기준, 조정 가능) |

| 구간 | 기간 | 용도 |

### 4.3 지표 (스윙 합산 곡선 · 시장별)

연환산 수익률(CAGR) · 최대 낙폭(MDD) · 샤프 · 소르티노 · MAR(CAGR/MDD) · 월간 승률 · 최장 연패 · 시장 노출률 · 연간 매매 수
비교 대상: 지수 단순 보유(KODEX 200·SPY), **같은 규칙의 무작위 진입 포트폴리오(200회)**, 몬테카를로(매매 순서 1만 회)로 낙폭 95% 구간

### 4.4 실험 예산 (개발 구간에서만, 최대 6개)

| # | 실험 | 비교 |
|---|------|------|
| E1 | 기준선: v2.1을 계좌 시뮬레이터로 | — |
| E2 | 스윙 위험 1% / 2%(현행) / 3% — 합산 MDD·CAGR 비교 | 3 |
| E3 | 품질 점수 문턱: 전부 매수(현행) vs 상위 절반만 | 2 |
| E4 | 쿨다운: OBV(현행) / 없음 / 고정 10거래일 | 3 |
| E5 | 시장 국면 필터(지수 EMA100)를 계좌 신규 진입에 적용 | 켬 / 끔 |
| E6 | 무작위 진입 포트폴리오 대조군 (최종 후보 규칙 그대로) | 200회 |

채택은 **MAR(CAGR/MDD)** 기준, 차이가 무작위 반복의 표준편차보다 클 때만. 그 외는 단순한 쪽(현행)을 유지.

## 6. 실전 반영 관문 (홀드아웃 기준, 결과 보기 전 고정)

1. 홀드아웃 CAGR > 0 이고 **MAR ≥ 0.5**
2. 홀드아웃 MDD ≤ 25%
3. 같은 규칙 무작위 진입 포트폴리오 대비 **MAR 상위 10%** 안
4. 국내·미국 각각 홀드아웃 순 기대값 > 0 (한쪽만 통과하면 그 시장만 반영 검토)

하나라도 미달이면 실전 반영하지 않고 결과를 그대로 기록한다.

## 7. 한계 (미리 밝혀 둠)

- 상장폐지 종목을 못 구하면 생존 편향은 줄일 뿐 없애지 못한다
- 스윙끼리 자금을 공유하지 않으므로, 하락장에 여러 스윙이 동시에 손절되는 것을 막는 장치는 없다 — 합산 곡선으로 크기만 보여준다
- 후보군이 "지금 살아 있는 종목"이라 생존 편향이 남는다 (상장폐지 종목을 받으면 일부 완화)
- 장중 규칙(5분 연속 확인·추격 제한·장중 붕괴)은 일봉으로 근사한다 — `STOCK_INTRADAY_SAMPLE`이 쌓이면 재확인
- 오더블럭이 무작위 진입을 못 이기면(관문 3), 그것이 결론이다
